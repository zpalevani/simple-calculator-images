# Calculator and mini dashboard

A browser-based HTML, CSS and JavaScript learning project featuring a basic calculator, a weather display and a task list.

## Run locally

Download or clone the repository and open `index.html` in a browser. No build step is required.

## Features and limitations

- Calculator: basic arithmetic, decimals, clear and delete controls.
- Weather display: a city selector and sample weather values; the current code does not fetch live weather.
- Task list: add, complete and delete tasks with optional due dates. Tasks are held in the page and reset on reload.

## Files

- `index.html`: dashboard layout
- `style.css`: visual styling
- `code.js`: calculator and task interactions
- `cat1.jpg`, `dog1.jpg`: page images
- `prompts.txt`: project prompts
